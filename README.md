# FoodBridge 🍲

FoodBridge is a software application designed to reduce food waste by connecting food donors (restaurants, event organizers, and individuals) with local charities, shelters, and volunteers.

## ✨ Key Features
* **Donor Portal:** Easily list surplus food with quantity, pickup location, and expiration details.
* **Receiver Dashboard:** Browse available food donations in real time and claim pickups.
* **Logistics & Tracking:** Coordinate delivery schedules between donors and volunteers.
